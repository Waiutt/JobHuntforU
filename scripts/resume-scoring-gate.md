# Resume Scoring Gate — 简历×岗位 匹配度评估策略（循环终止门禁）

本策略用于简历生成/修改的**质量门禁**：任何简历在输出或投递前，必须通过三角色匹配度评估，
**总分 ≥ 95 才允许输出**；未达标则循环优化（补岗位关键词、量化成果、自评契合）直至达标——这就是"循环终止条件"。

## 为什么需要

简历与岗位的匹配度决定初筛通过率。单一视角判断易主观，故引入三个招聘环节的真实角色视角加权评分：

| 角色 | 权重 | 关注点 |
|---|---|---|
| **HR 视角** | 35% | 筛选漏斗：基础信息完整度、实习/项目数量、岗位关键词覆盖率、证书板块 |
| **部门成员视角** | 35% | 干活的人：核心技能命中率、进阶能力、工具链匹配、量化成果密度、经历深度 |
| **部门负责人视角** | 30% | 业务结果：成果导向（提升/增长/覆盖/准确率等）、独立主导性、方法论沉淀、自我评价契合度 |

总分 = 0.35 × HR + 0.35 × 成员 + 0.30 × 负责人。

## 循环终止（Loop Termination）

```
生成/修改简历
   ↓
三角色评分（HR / 部门成员 / 部门负责人）
   ↓
总分 ≥ 95？ ──否──→ 定位失分项（关键词/量化/自评）→ 优化简历 → 重新评分（回到上一步）
   ↓ 是
输出简历（允许投递）—— 循环终止
```

- **达标阈值**：总分 ≥ 95（PASS），允许输出/投递
- **未达标**：FAIL（禁止输出），必须回改简历后重新评分，直至 PASS
- 每次评分结果（三视角分 + 总分 + PASS/FAIL）记录到投递日志，便于复盘

## 使用方式

```bash
# 基本评分（默认不显示分项明细）
python scripts/resume-scorer.py <简历文件> <岗位族>

# 显示分项明细（定位失分点）
python scripts/resume-scorer.py <简历文件> <岗位族> --debug
```

### 岗位族

`ai_pm` | `data_ops` | `game_ops` | `new_media` | `content_ops` | `platform_ops` | `data_analyst`

### 示例输出

```
========================================================
简历: <姓名>_AI产品经理_简历.pdf
岗位族: ai_pm
--------------------------------------------------------
HR视角(35%)        100/100
部门成员视角(35%)      95/100
部门负责人视角(30%)      96/100
--------------------------------------------------------
综合匹配度          97.0/100  PASS (>=95), 可以输出
========================================================
```

## 扩展

- 岗位族关键词库在 `resume-scorer.py` 的 `ROLE_KEYWORDS` 中，可按需增删岗位与关键词
- 支持 `--jd 岗位描述文件` 参数（预留）：可进一步用岗位 JD 文本做语义匹配
